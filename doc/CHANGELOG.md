## 7.9.0 — 2026-10-12

### Added
- **Capabilities** (`includes/Core/capabilities.php`): `certificate_generator_view`, `_issue`, `_manage_templates`, `_manage_settings`. Every user with `manage_options` has all four (a `user_has_cap` filter, nothing stored), so admins see no change; role editors can grant them to other roles. The plugin's ~100 `manage_options` checks now use them.
- **School Coordinator role** (`certificate_generator_school_coordinator`: `read`, `view_admin_dashboard`, view, issue), created on first `init`. An admin picks the coordinator's school on **Users → Edit user → Certificate Generator → School** (user meta `certificate_generator_school`). A coordinator sees Students, Teachers, Bulk Import (students/teachers only), Download Certs, Bulk Send and Documentation, all limited to that school: lists, counts, filter dropdowns, "select all matching", ids posted to bulk actions and AJAX, the edit forms (school locked), Bulk Send recipients and email picker, download jobs and single downloads, and imports (every row saved to their school). The Dashboard sends them to Students. A coordinator with no school assigned sees nothing and can't add records. Templates, schools, events, revoke, analytics, logs, export and settings stay with admins.
- **Template import: `field_N_name`** — what each field shows, as the template editor saves it.
- **My Certificates** (`[certificate_generator_my_certificates]`, `includes/Public/my-certificates.php`): a recipient types their email and gets a signed sign-in link (email | expiry | HMAC with `wp_salt( 'auth' )`, 30 minutes, nothing stored). Opening it moves the token into an HttpOnly, SameSite=Lax cookie and redirects to the clean URL. The list (students and teachers) has Download, Verify & share, Download all (ZIP) and a per-certificate "Show my name when someone verifies this" switch (AJAX `certificate_generator_wallet_show_name`, ownership checked against the cookie's email, recorded as a `name_visibility` event). The form redirects with the same message for known and unknown addresses; 5 requests per IP per 10 minutes, one link per address per 2 minutes. Requests are handled on `template_redirect`, so hide-login plugins don't break it. Mail goes through `Mailer`; filters `certificate_generator_wallet_email_subject` and `_body`.
- **Migration 013** adds `show_name TINYINT(1) NOT NULL DEFAULT 1` to `wp_certificate_generator` and `wp_cg_certificates`. When 0, `SerialNumberService::verify()` returns an empty name and `name_hidden: true` (full and masked answers alike) and the verify page shows "Hidden by the recipient".
- **Sharing** on full verify results: X, WhatsApp and copy-link next to LinkedIn, all sharing the `?code=` link. Option `certificate_generator_linkedin_org_id` adds `organizationId` to LinkedIn's Add to Profile link. Open Graph and Twitter-card tags for a shared `?code=` link (well-formed code, within the verify rate limit, masked or no name, not recorded as a verification; skipped when Yoast, Rank Math or AIOSEO is active).
- **Share text** for X and WhatsApp is translatable and filterable: `certificate_generator_share_text()` (default "My {certificate_type} certificate from {issuer} — verify it here:"), filter `certificate_generator_share_text`. Action `certificate_generator_settings_sharing_fields` adds rows to Settings → General → Recipients & sharing (options registered in the `certificate_generator_recipients` group). The Pro add-on uses both for an editable **Share text** setting.
- **Personal data export and erasure** (`includes/Core/privacy.php`) for Tools → Export / Erase Personal Data: student and teacher rows, both certificate tables, email logs and queue rows, 50 rows per table per page. Erase deletes records, logs, queue rows and cached PDFs, and anonymises certificates (`[erased]`, no email, `certificate_data`, `extra_fields` or PDF path; history `meta_json` cleared) so they still verify.
- **Certificate Register** (Certificate Generator → Register, `cg-register`, `includes/Admin/register.php`, capability `certificate_generator_view`): every issued certificate from `wp_certificate_generator` with serial, verification code, recipient, email, school, type, event (template of the latest `wp_cg_certificates` row), issued, expires, status and revoke reason. Filters: type, school, event, issue dates, status (valid / expired / revoked, by the verify page's rules). Downloads: CSV (UTF-8 BOM, formula-escaped) and an A4 landscape PDF through mPDF (header row on every page, non-Latin names shaped; `MpdfCanvas::config()` and `MpdfCanvas::html()`). School Coordinators get only their own school.
- **Verify page created automatically**: `certificate_generator_ensure_verify_page()` adopts a published page with `[certificate_generator_verify_certificate]` or creates "Verify Certificate", on activation and daily (with the QR cleanup cron), and stores it in option `certificate_generator_verify_page_id`. QR codes and `{verify_link}` use `certificate_generator_verify_page_url()`. Before this, a site without the page got QR codes pointing at the home page and emails pointing at `/verify-certificate/`.
- **Setup checklist** has 6 steps: publish the verification page (one-click "Create it now"), template, test certificate, records (links to Bulk Import and its sample CSVs), issue, and verify a certificate (done at the first `verified` event). Each user can hide it (user meta `certificate_generator_checklist_hidden`) and show it again from Documentation → Getting Started. The welcome banner links to it.
- **Sample CSVs** for students, teachers, schools and templates in `assets/samples/`, linked from the Documentation page, the Templates import tab and the guide. They fit together (a template for every certificate type) and import cleanly (`SampleCsvTest`).

### Changed
- **Text sits where the template editor shows it.** The editor centres each field on its Y position, but the PDF drew the text's baseline there, so text printed about a third of its height too high. Each line is now centred on Y (`certificate_generator_line_baselines()`: baseline 0.35 em below the line's middle, lines 1.2 em apart; wrapped lines are centred as a block). The debug boxes on previews now match the text. Regenerated certificates move down slightly; check templates that were nudged up to compensate.
- **PNG downloads match the PDF.** `PngGenerator` treated X as the field's left edge and drew text a third too large (GD renders at 96 dpi, the size was scaled for 72), and never shrank or wrapped long text. It now uses the PDF's fit-to-width, wrapping and placement, measured with GD (`PngGenerator::gd_size()`); the serial number gets the size fix too.
- The single-certificate download links (`action=download_certificate[_png]`, used by the Pro school ZIP shortcode) also accept School Coordinators, for their own school only.
- Option `certificate_generator_search_requires_link` (Settings → General → Recipients & sharing, default off): `[certificate_generator_student_search]` renders the My Certificates form instead of listing certificates for any typed email, and its ZIP endpoint answers 403 unless the email is the signed-in one.
- `certificate_generator_student_certificates_for_email()` takes an `$entity` (`students` or `teachers`) and returns each certificate's `serial_number`.
- The unfiltered "send to every record" AJAX (`certificate_generator_start_bulk_send`, not used by the current Bulk Send page) is admin-only.

## 7.8.0 — not released on its own, shipped in 7.9.0

### Added
- **Reissue** (Revoke page → History → Reissue): keeps the serial and verification code, bumps `revision`, records a `reissued` event with the reason; the verify result shows "Corrected on …". AJAX `certificate_generator_reissue_certificate` (`includes/Admin/revoke-certificate.php`).
- **Template snapshots**: **Migration 012** adds `revision` and `layout_snapshot` to `wp_cg_certificates`. The template layout is stored on first issue (the values still come from the record), and re-downloads render from the snapshot, so later template edits don't change issued certificates.
- **Per-field font, size, colour and UPPERCASE** in the template editor; fields without overrides use the template font.
- **Custom-text slots** mixing literal text with `{field}` tags.
- **Import check step** (Bulk Import → Students / Teachers / Schools): upload → check → import. The three importers now share one pipeline (`certificate_generator_import_run()` + `certificate_generator_import_entities()` in `includes/Services/bulk-import.php`); the check is a dry run of that same code (`CertificateGenerator_Import_Writer` `$dry_run`), so its counts are the import's. It shows the column mapping with a per-column override, required columns still unmapped (Import disabled), the date order (asked when values like 03/04/2026 fit both), update-or-leave for existing records, the first 5 rows as stored, and names too wide for their field (`PreSendCheck::name_too_long`). Uploads are kept in `cg_certificates/private/import-*.csv` between steps and deleted after the import, or by the daily cron after 2 hours.
- **Delimiter and encoding detection**: comma, semicolon or tab; UTF-8 (with or without BOM), UTF-16 and Windows-1252 converted; undecodable text stops the import. Header aliases ("Name", "Email Address", "School", "Date", "Type", …) and a fixed header normaliser — upper-case letters used to be stripped, so "Email" became "mail".
- **Sample CSV** per tab, built from the importer's own field lists plus registered extra fields. The issues CSV now has a UTF-8 BOM.
- **Preview with a real record**: Preview Certificate can use one of the 50 newest records of the template's type, with its existing serial so the QR verifies; nothing is issued.
- **Non-Latin text on certificates** (`src/Services/MpdfCanvas.php`): a certificate with any character outside Latin-1 renders through mPDF behind the slice of FPDF's API the renderers use, so positions, fit-to-width and wrapping are unchanged. Each line is split into script runs: Latin keeps the field font (its TTF via `get_ttf_path_for_gd()`), Indic and Arabic runs use bundled fonts (`assets/fonts/unicode`: FreeSerif; Lohit Telugu/Kannada; Noto Sans Oriya — today's Noto builds use OpenType lookups mPDF 8.3 can't read). Widths are measured after shaping. Latin-1 certificates stay on FPDF (`PdfCacheTest` unchanged); `CERTIFICATE_GENERATOR_PDF_RENDER_REV` 4 re-renders cached PDFs that printed "????". Text for tFPDF with a TTF is now passed as UTF-8 (`certificate_generator_pdf_text()`), fixing non-Latin characters with uploaded fonts. PNG downloads of Indic/Arabic certificates return the PDF. `bin/build-zip.ps1` drops mPDF's own 88 MB `ttfonts`.
- **Fix:** `get_ttf_path_for_gd()` returned nothing for Helvetica/Times/Courier (FPDF core fonts) and five definitions without an embedded file, so PNG downloads of those templates had no text. They now use the bundled metric-compatible twin (Arimo, Tinos).
- The old one-step POST (`submit_students` etc.) still imports directly, for scripts and `bin/bench-bulk-import.php` (10,000 rows: check 0.7 s, import 2.1 s, re-import 4.8 s, 27 MB peak).

## 7.6.0 — 2026-10-09

### Changed
- **Unique `certificate_generator_` prefix everywhere (WordPress.org review requirement).** About 300 global names moved off the 2-letter `cg_` / unprefixed names: functions (`cg_*`, `_cg_*`, `bulk_import_*`, `generate_certificate_pdf*`, …), classes (`CG_*` → `CertificateGenerator_*`), plugin-defined constants (`CG_QUEUE_*`, `CG_PDF_RENDER_REV`, … → `CERTIFICATE_GENERATOR_*`), options, transients, hooks (`cg_settings_tabs`, `cg_feature_flags`, `cg_email_sent`, … → `certificate_generator_*`), AJAX actions (incl. the old `cert_*`), cron hooks and shortcodes. Feature-flag names (`CG_USE_*`), nonces, form fields, CSS classes and `wp_cg_*` table names are unchanged. **Migration 010** (`src/Database/Migrations/Migration010_PrefixRename.php`) renames stored options and persistent counters in place (serial-number counters included), drops caches, and re-schedules queued cron events under the new hooks; the runner falls back to the old `cg_db_version` so earlier migrations never re-run, and migrations now run before any settings code in `Plugin::boot()`.
- **Shortcodes renamed** (old names removed): `[certificate_generator_student_search]`, `[certificate_generator_teacher_search]`, `[certificate_generator_school_search]`, `[certificate_generator_verify_certificate]`. Migration 010 rewrites the old tags in post content and Elementor data, so existing pages — including the verification page that printed QR codes link to — keep working.
- **WordPress.org guideline test**: `tests/Compliance/wporg-guidelines.json` lists the 18 Detailed Plugin Guidelines plus review-team rules; `WpOrgGuidelinesTest` (unit suite) checks every automated item against the shipped files.
- **LMS and WooCommerce integrations moved to the Pro add-on.** The listeners, mappers, "Issue to past completions" and the six mapping pages now live in `certificate-generator-pro/src/` and need a Pro license. The free plugin keeps email sending (wp_mail, SMTP, Sender.net, Mandrill) and email templates. The mapping tables stay in the free plugin's schema, so existing mappings come back when the add-on is activated. New extension points: `cg_feature_flags` (filter) and `cg_admin_menu_integrations` (action).
- **Custom font (.ttf) upload is now part of Pro**, not only Business (`certificate-generator-pro/includes/custom-fonts.php`).

### Added
- **LearnPress integration** (`src/Integrations/LearnPress/`, **Certificate Generator → LearnPress**): issue a certificate when a student finishes a mapped LearnPress course, with track certificates. Off until enabled under Settings → Tools (`CG_USE_LEARNPRESS_INTEGRATION`).
- **Issue to past completions** (`src/Integrations/LmsBackfill.php`): a button on each course mapping (Tutor LMS, LearnDash, LifterLMS, Sensei, LearnPress) that issues the certificate to students who finished before the course was mapped. Runs in WP-Cron batches of 25 and skips anyone who already has it.

- **Built-in font library on the Fonts page** (`src/Admin/Pages/FontsPage.php`): every plan now sees the 27 bundled fonts, how many templates use each, and a note on fonts that print as Helvetica. **Download sample PDF** renders one line per font through the same FPDF path certificates use.
- **Email me a test certificate** (template editor, every plan): renders the saved template with your name and emails the PDF to your admin address. It isn't logged, so it doesn't use the monthly email allowance (`src/Admin/TestCertificate.php`).
- **One setup checklist**: the Dashboard and Documentation → Getting Started now show the same four steps (`cg_setup_steps()`), including the test certificate. Removed the "Run migration" step for new installs, and fixed the WP Mail SMTP link (`wp-mail-smtp`).
- **`{site_name}` email placeholder**. The default email is now signed with the site name instead of "The GEMA Team" (new installs; saved templates are unchanged).
- **Resend all failed** (Email Logs): one button queues every failed email that hasn't since been delivered, one per certificate and address (`src/Email/EmailResender.php`).

### Fixed
- `secure_log()` sanitized messages through a helper that no longer exists after the security-helper cleanup; it now uses `sanitize_text_field()` directly.
- The certificate-generation progress poll (`check_certificate_progress`) now requires `manage_options`; both progress handlers unslash and sanitize their nonce. Bulk-edit input is unslashed before use. Settings field labels, the email-log pagination and the bulk-download counter are escaped.
- Removed the global admin `$_POST`/`$_GET` rewrite and the security headers sent from `admin_head` (too late to take effect).
- (Pro add-on) The school bulk ZIP list called a `cg_format_date()` function that doesn't exist, so it crashed for any student with an issue date. Removed two unused REST helpers, one of which called `generate_certificate_pdf()` with the wrong arguments.
- **Accented names lost their accents when they wrapped** ("José" printed as "Jos?"): wrapped lines were converted to Latin-1 a second time.
- **Email Logs → Resend did nothing**: it called an AJAX action that had been removed. It now sends again immediately through the normal send path and shows the reason if it fails. Rows logged by LMS auto-issue say to resend from the student's row instead.
- **Bulk Send skipped new certificates for anyone already emailed.** "Already sent" was decided per email address, so a second certificate for the same person never appeared under "Not sent yet". It is now per address + certificate type (`cg_recipient_set_sql()` in `includes/Admin/filters-api.php`). Log rows from older versions with no type still count for the whole address, so upgrading doesn't re-send anything.
- **Corrected names now reach the verification page.** Fixing a recipient's name and sending again re-rendered the PDF with the same serial, but `/verify` kept the old name, because the record for that serial was never updated. It now follows the corrected name (`cg_sync_certificate_record_name()` in `includes/Services/certificate-search.php`). Teacher and school records no longer get a blank name from an empty student field.
- **LMS auto-issue emails** left `{result_link}`, `{verify_link}` and `{email}` unreplaced. They now use the same placeholders as every other send.
- **Large imports could stall forever on retry.** After a time-limit stop, re-uploading re-updated every earlier row, which is slower than inserting, so each retry stopped sooner. The stop row is now remembered for that exact file, and the next upload continues from it (`CG_Import_Writer::resume()`).
- **Re-importing duplicated rows that have no email.** They now match on name + school (+ type and date) against existing rows without an email.
- **Plan-gating bypass closed.** Blanking the license-server URL switched on offline `PRO-`/`BIZ-` prefix keys, so `BIZ-anything-LIFETIME` gave a free Business plan. Offline keys now need the `CG_LICENSE_LOCAL_KEYS` constant (development only), and a blank URL falls back to the default server. Licenses already activated offline keep working.
- **Certificate PDFs could be found by counting.** Files were named `certificate_students_row_1000.pdf`, `…1001.pdf` and so on, and the folder could be listed. Names now end in a 12-character keyed hash (`cg_certificate_file_stem()`), and `cg_certificates/` has an `index.php`. Each certificate's old file is deleted the next time it renders. **After updating, run Settings → Tools → Clear Cache once** to remove the rest.
- **Rate limits could be dodged with a fake `X-Forwarded-For` header.** Forwarded headers are now trusted only when the request comes from a proxy on a private network. Sites behind Cloudflare without real-IP restoration can return the visitor IP through the new `cg_client_ip` filter.
- **School bulk download showed a school's student list for a partial name** (one letter was enough). It now needs the exact school name, and the ZIP link carries a nonce and `rel="nofollow"`, so a guessed or crawled URL can't start rendering every PDF.
- **Email Logs → Export CSV** failed with an SQL error (`LIMIT -1`).

### Changed

Sites that saved the old `tlvapi.myimage.fun` host are switched to the new one automatically. The Business "Contact us" link now opens an email to techlovev@gmail.com.

Email templates and recipient renewal reminders are now free. The paid features moved to a separate **Certificate Generator Pro** plugin (`certificate-generator-pro/`): the License and API Settings tabs, `CG_License_Manager`, the REST API (`certificate-generator/v1`), the `[school_bulk_certificate_download]` shortcode, and custom font upload (Business). Uploaded fonts still render and can be removed without it. Usage counting and its monthly reset cron are removed; the multisite plan notice is gone. New hooks for the add-on: `cg_settings_tabs`, `cg_settings_tab_{key}`, `cg_fonts_page_message`, `cg_fonts_page_upload_card`.

Arial, Times New Roman, Georgia, Verdana Bold, Comic Sans, Garamond and Rumble Brave Script were bundled without a redistribution license. They're now Arimo, Tinos, Gelasio, Noto Sans Bold, Comic Neue, EB Garamond and Great Vibes (Apache 2.0 / OFL, `lib/fpdf/font/FONTS-LICENSE.txt`). - **Long names shrink to fit their field.** Text wider than its field is drawn smaller, down to 60% of the template's font size (never below 8 pt). Only text that still doesn't fit wraps onto more lines (`cg_fit_font_size()`). Cached PDFs re-render once (`CG_PDF_RENDER_REV` 2).
- The Business plan's "19,000+ Font Library" label is now "Custom Font Upload (.ttf)". Every plan already gets the same 27 built-in fonts, so custom upload is the only font feature that is Business-only.
